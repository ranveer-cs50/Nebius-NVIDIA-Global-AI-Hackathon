# AI Research Assistant

An AI-powered research assistant built for the Nebius × NVIDIA Global AI Hackathon.

## Goal

Build a research workflow that searches the web for relevant sources and uses AI to generate evidence-grounded answers with source links.

## Planned Features

- Web search using Tavily
- AI-powered synthesis using a model available through Nebius
- Source links for verifying claims
- Clear separation between retrieved evidence and generated answers

## Tech Stack

- Python
- Tavily Search API
- Nebius API
- Git and GitHub

## Status

Early development. Features and architecture are subject to change.
